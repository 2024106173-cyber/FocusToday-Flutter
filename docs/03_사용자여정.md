# 3. 사용자 여정 · User Journey

## 상황

김서연(가상)은 수업 후 지하철에서 남은 과제와 생활 할 일을 빠르게 확인한다.

| 단계 | 행동·목표 | 리뷰 연결 | 감정(가설) | v2 대응 |
|---|---|---|---|---|
| 1. 진입 | 오늘 목록 열기 | R03: 알림 장점 | 기대 | 오늘 요약 카드 |
| 2. 탐색 | 학교·생활 구분 | R01·R02: 색 요청 | **혼란, 최저점** | 카테고리 색+라벨 |
| 3. 판단 | 우선순위 결정 | 직접 리뷰 없음 | 불확실 | 중요도 정렬/문자 |
| 4. 행동 | 할 일 추가/완료 | 직접 리뷰 없음 | 안도 | 빠른 추가/되돌림 |
| 5. 재확인 | 완료 여부 확인 | 직접 리뷰 없음 | 안정 | 완료함 탭 |

이 감정 서술은 실제 사용자 조사 결과가 아닌 페르소나 기반 시나리오다.

## 확장 4종

1. **사용 기기:** 작은 휴대폰 세로 화면, 이동 중 한 손 사용.
2. **AI 활용:** 자연어 입력의 자동 카테고리 추천은 가능하나 오분류 위험과 범위를 고려해 실제 기능은 제외. AI를 반론 생성 도구로만 사용.
3. **설계 원칙:** 목록의 일관성, 색+문자 이중 부호화, 실행 취소의 가역성.
4. **필요 데이터:** 작업 ID·제목·카테고리·우선순위·마감일·완료 여부·메모. 로컬 GET 데이터.

## 후속 검증 계획

학생 3~5명을 대상으로 특정 카테고리/우선순위 작업 찾기를 시키고 시간·오류·주관적 혼란을 수집할 수 있다. **이번 과제에서 실제 사용자 테스트를 진행하지 않았다.**
