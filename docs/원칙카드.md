# 오늘한눈 v2 · 디자인 원칙 카드

**P1. 맥락이 보이는 목록**

- 규칙: 작업 행에 카테고리 텍스트 '학교/생활/개인'을 고정 표시
- 연결 근거: Google Tasks 공개 리뷰 R01, R02의 시각 구분 요청
- 화면 적용: P01~P05

**P2. 색 외에도 문자를 남긴다**

- 규칙: 색은 보조 힌트이며 중요한 의미는 텍스트에도 나타나야 한다
- 연결 근거: AI의 접근성 반론을 반영한 수정 판단
- 화면 적용: P01~P05, P07

**P3. 완료는 되돌릴 수 있다**

- 규칙: 체크 후 완료함에서 확인 가능하며 SnackBar 실행 취소 제공
- 연결 근거: 가역성에 관한 AI 반론 (기존 앱의 실증적 결함이라고 주장하지 않음)
- 화면 적용: P04, P05

**P4. 실패와 대기도 화면에 보여준다**

- 규칙: 로딩, 오류, 빈 상태에 별도 설명과 다음 행동 표시
- 연결 근거: 중간프로젝트 UI 구현 필수 조건
- 화면 적용: P08~P10

**P5. 제출 범위를 지킨다**

- 규칙: 로컬 json-server GET은 사용, 실제 저장·로그인·결제·AI 추천은 제외
- 화면 적용: 모든 화면
