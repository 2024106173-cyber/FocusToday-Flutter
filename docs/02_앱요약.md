# 2. 앱 설명 요약 · One Page

## 오늘한눈 (Focus Today)

**한 문장:** 수업과 생활 할 일을 함께 관리하는 대학생이 오늘의 우선순위를 빠르게 이해하는 할 일 목록 UI.

### 목표

앱을 열자마자 어떤 작업이 어느 카테고리에 있고 무엇을 먼저 할지 짧은 시선 이동으로 이해하도록 한다.

### 주요 사용자 페르소나

- 김서연(가상), 22세 대학생
- 학교 과제·개인 일정·생활 업무를 한 앱에 기록
- 이동 중 휴대폰을 열어 남은 작업 확인
- 필요한 것: 맥락/중요도 즉시 인지, 실수로 완료해도 되돌릴 수 있음
- **실제 인터뷰가 아닌 디자인 가상 인물**

### 사용자 문제

리뷰 R01, R02에서 모바일 목록 색 구분 개선을 요청한다. 항목별 맥락 표시가 충분히 눈에 띄지 않을 수 있다는 가설을 세웠다.

### v2의 핵심 가치

1. **맥락 명확화:** 학교·생활·개인 색상과 텍스트 라벨 함께 표시
2. **우선순위 표시:** 높음·보통·낮음 텍스트와 색, 중요도 정렬
3. **안전한 완료:** 완료함에서 검색/되돌리기 가능하도록 UI 구성

### 검증할 성공 기준

- 5초 안에 '학교'의 높은 우선순위 항목을 찾는가
- 완료한 항목을 어디서 확인/복구하는지 말할 수 있는가
- 색을 구별하기 어려워도 텍스트만으로 이해하는가

숫자 5초는 향후 테스트 목표이며 **달성 실적이 아니다**.
