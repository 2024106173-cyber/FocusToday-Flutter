# 1. 현행 유사 앱 분석

작성: 전시우 / 조사일: 2026-10-28

**비교 대상:** Google Tasks. Gmail·Calendar 연동, 별표 표시, 하위 할 일 등 기능이 있는 기존 할 일 관리 앱이다. 본 v2는 앱 전체를 복제하지 않고 **모바일 목록을 빠르게 읽는 경험**에 집중한다.

공식 출처: https://play.google.com/store/apps/details?hl=ko&id=com.google.android.apps.tasks

## 스토어 현황

- 조사 당시 상단 표시: **4.6점**, **리뷰 약 61.2만 개**. 장치·지역·시점에 따라 집계가 다를 수 있다.
- 별점 분포: 스토어 원본 그래프 화면을 캡처해 넣어야 한다. 개별 구간 비율은 확인되지 않아 생성하지 않았다.
- 원본 화면: 스토어의 화면을 직접 캡처해 카테고리 구분이 필요한 부분을 표시해야 한다.

## 리뷰 근거와 유형

작성자 이름은 보고서에서 제거했다. 날짜는 원본에 표시되어 있다. **개별 리뷰의 별점은 원문 화면과 대조해야 한다.** 아래는 공개 리뷰의 의역이며 별도의 설문 결과가 아니다.

| ID | 게시일 | 별점 | 확인한 내용(요약) | 분류 |
|---|---|---|---|---|
| R01 | 2026-05-20 | 원본 확인 필요 | 섹션별 색상 및 여러 시간 알림을 요청, 위젯·캘린더 동기화는 긍정 평가 | 시각 구분 / 알림 / 강점 |
| R02 | 2026-08-27 | 원본 확인 필요 | 모바일에서 목록별 색상 구분이 되지 않아 어려움 | 시각 구분 |
| R03 | 2026-09-29 | 원본 확인 필요 | 미완료 작업의 다음 날 알림을 긍정 평가 | 기존 강점 |

## 분석

- **공통 요구:** R01과 R02가 목록/섹션 시각 구분을 개선해 달라고 요청했다.
- **설계 가설:** 작업 제목과 목록 맥락이 동시에 드러나면 스캔 부담이 줄어들 수 있다.
- **유지할 장점:** R03이 좋아한 미완료 일정 인지 경험을 방해하지 않는다.
- **이번 과제의 한 가지 핵심:** 작업 항목에서 소속 카테고리가 눈에 잘 띄도록 한다.
- **제외:** 다중 알림·반복 알림 실제 로직. UI 과제의 구현 범위를 넘는다.

## 정확성 한계 및 필수 캡처

3건의 공개 리뷰는 전체 사용자를 대표하지 않는다. 실제 기존 앱의 문제 원인은 테스트 없이 확정할 수 없다. 다음 다섯 장은 제출자가 직접 스토어에서 확인해야 한다.

1. 앱 평점과 별점 분포 (10/28 기준 또는 새 확인일 표기)
2. R01, R02, R03 리뷰 화면, 이름 가림 및 각 별점 확인
3. 기존 앱의 목록 화면과 문제가 되는 시각 구분 지점 표시
