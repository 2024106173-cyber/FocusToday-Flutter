# 8. v1/v2 전후 비교 · 설계 가설

**주의:** 실제 Google Tasks와 개편 화면에 대한 정량 사용자 테스트를 하지 않았다. v1 설명은 공개 리뷰가 지적한 경험에 대한 **문제 가설**이고, v2는 본 프로젝트의 계획·구현 UI다.

| 항목 | 이전 상황(문제 가설) | v2 설계 | 채택 근거/한계 |
|---|---|---|---|
| 카테고리 구분 | 모바일 목록에서 구분이 어렵다는 리뷰 | 색 점과 학교·생활·개인 라벨 동시 표시 | R01, R02. 실제 소요 시간 검증 필요 |
| 중요도 | 여러 맥락이 섞이면 우선 작업 판단 부담 | 높음·보통·낮음 글자와 중요도순 정렬 | 독립 설계 가설, 직접 리뷰 없음 |
| 빠른 추가 | 작업 기록 시 여러 정보를 나중에 찾을 수 있음 | BottomSheet에서 제목·분류·중요도·기한 | 가상 페르소나 요구, 테스트 필요 |
| 완료 후 확인 | 체크 후 다시 찾아야 하는 부담 가능 | 완료함 탭·실행 취소·완료 취소 | AI 반론에 대한 설계 보완, 리뷰 직접 증거 없음 |
| 서버 상태 | 데이터가 비었거나 오류면 맥락 부족 가능 | 로딩·오류·빈 상태의 별도 안내 | 과제 필수 구현 조건 |

## 조정된 화면 요소

1. 최초 시안: 색만 있는 카테고리 점. AI 반론 후 색과 글자 병행.
2. 최초 시안: AI 자동 추천. 신뢰·범위 반론 후 수동 우선순위 ChoiceChip.
3. 최초 시안: 완료 체크 후 숨김. 가역성 반론 후 완료함과 실행 취소 추가.
4. 최초 주장: 개선 효과 확정. 검증 부족 반론 후 '후속 실험으로 확인할 가설'로 수정.

## 향후 UX 검증

- 참여자: 대학생 3~5명 모집 예정(미진행)
- 과제 A: 학교의 높은 우선순위 작업을 찾아 제목 읽기
- 과제 B: 실수로 완료한 작업을 찾아 복구하기
- 지표: 완료 시간, 오류 횟수, 사용자 인식 난이도
- 결과란: **미측정**. 수치를 임의로 기록하지 않는다.
